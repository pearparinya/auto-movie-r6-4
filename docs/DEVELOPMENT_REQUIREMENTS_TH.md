# DIRECTOR X — ข้อกำหนดพัฒนารวม
บันทึกจากคำสั่งผู้ใช้ วันที่ 13 ตุลาคม 2569 เวลา 07:22 น. (Asia/Bangkok)

เอกสารนี้เป็นขอบเขตที่ต้องพัฒนาและตรวจรับ ไม่ใช่รายการฟังก์ชันที่ทำเสร็จแล้ว
ผู้ใช้ต้องการพัฒนาเป็นอัปเดตชุดเดียว ทุกเมนูใช้งานจริง ไม่ใช่ mockup หรือปุ่มที่ไม่ทำงาน

## 1. หน้าตาและการนำทาง
- Native Android สไตล์สตูดิโอหนัง พื้น obsidian black ตัด amber gold ตัวอักษรไทยอ่านง่าย
- ภาพผู้พัฒนาขนาดเล็ก หนังที่กำลังสร้าง ภาพปก ชื่อเรื่อง ความคืบหน้า EP/ฉาก และปุ่มทำต่อเด่น
- Timeline: วางเรื่อง → ตัวละคร → ภาพฉาก → วิดีโอ → ส่งออก สถานะตามข้อมูลจริง
- เมนูหลัก: หน้าหลัก เรื่องของฉัน ตัวละคร ตั้งค่า ย้ายอัปเดตไปตั้งค่า
- ย้อนกลับชัดเจน การ์ดล็อกอธิบายเหตุผลและจำนวนงานที่ขาด

## 2. เรื่อง บท และการทำต่อ
- สร้าง เปิด เปลี่ยนชื่อ ทำสำเนา เก็บเรื่องที่จบแล้ว
- ช่อง แนวเรื่อง อัตราส่วน ความยาวฉาก จำนวน EP/ฉาก: กำหนดเองหรือ AI ประเมิน
- คงโหมด Flow/Veo 3.1 Lite 8 วินาที 9:16 และกล้อง Locked-off static ตามการตั้งค่าเรื่อง
- แยก EP และฉาก แก้บทพูด ระบุผู้พูด แยกเสียงบรรยายจากบทพูดตัวละคร
- เก็บ EP/ฉากล่าสุด เปิดกลับมาทำต่อได้ ไม่บังคับเริ่มเรื่องใหม่

## 3. MASTER และความเหมือนตัวละคร
- MASTER รายคนและรายเรื่อง ชื่อ บทบาท ภาพตัวอย่าง จับคู่ไฟล์และตัวละครให้ถูกคน
- แนบ MASTER ของคนที่อยู่ในฉากทุกครั้ง คงหน้า ผม สีผม ลักษณะเฉพาะ รูปร่างและสัดส่วน
- คงไหล่ ลำตัว เอว สะโพก แขน ขา และสัดส่วนหน้าอกของตัวละครผู้หญิงผู้ใหญ่ให้ใกล้เคียงต้นฉบับ
- เป้าหมายผู้ใช้: ความเหมือนอย่างน้อย 95% เป็นเป้าหมายคุณภาพ ไม่กล่าวอ้างค่าที่วัดจริงหรือรับประกันหากไม่มีวิธีประเมิน
- ชุด สถานที่ การกระทำมาจากบท เปลี่ยนตามเหตุการณ์ ไม่คัดลอกชุด MASTER โดยอัตโนมัติ
- Prompt กระชับเชิงบวก: MASTER → ชุดรายคน → สถานที่/สิ่งของ → การกระทำ → สีหน้า/สายตา
- เปรียบเทียบ MASTER กับผลลัพธ์ ปุ่มผ่าน/ต้องแก้ แก้เฉพาะส่วน เก็บภาพเดิม และให้ผู้ใช้ตรวจรับ
- รูปผู้ใช้ที่อนุญาตให้รวมใน GitHub/ APK แล้ว ใช้ทดสอบได้ทันทีโดยไม่หาไฟล์ พร้อมเปลี่ยนรูปได้
- หากเปลี่ยน MASTER แจ้งฉากที่ต้องตรวจใหม่ ไม่ลบงานเดิม

## 4. ความต่อเนื่อง
- เก็บชุด สถานที่ เวลาในเรื่อง อุปกรณ์ เหตุการณ์ก่อนหน้าและจุดส่งต่อ
- คงชุดในเหตุการณ์ต่อเนื่อง เปลี่ยนตามวัน/เหตุการณ์
- หากแก้บทแจ้งฉากที่ได้รับผลกระทบ เก็บผลลัพธ์เดิม

## 5. สั่งงาน ChatGPT ต้องทำงานจริง
- ทุกเมนูที่สั่ง ChatGPT ต้องเปิดแอป ChatGPT แยกจาก DIRECTOR X จริง ผ่าน Android share พร้อมข้อความและภาพที่ตรงงาน
- ตรวจและแสดง preview คำสั่ง/ไฟล์ก่อนส่ง: สร้างเรื่อง ทดสอบภาพ สร้างภาพฉาก แก้ภาพ ปก และทั้งเรื่อง
- มีคัดลอก ส่งซ้ำ และแจ้งข้อผิดพลาดเมื่อเปิดหรือส่งไม่ได้
- หากข้อความไม่เข้า ใช้คำสั่งที่คัดลอกไว้วางได้ หากรูปเข้าไม่ครบต้องแจ้ง/ให้ตรวจ
- เปิด ChatGPT ไม่เท่ากับได้รับข้อมูลหรือสร้างงานสำเร็จ ผู้ใช้ยืนยันรับข้อมูลก่อนเปลี่ยนสถานะ
- ผู้ใช้กดส่งข้อความใน ChatGPT เอง ไม่อ้างควบคุมมือถือหรือส่งผ่าน Plus/API อัตโนมัติหากไม่ได้ทำจริง
- กลับเข้า DIRECTOR X แล้วอยู่เรื่อง/ฉากเดิม ไม่เสียงาน
- สถานะแยก: เตรียมคำสั่ง ส่ง/รับข้อมูลยืนยันแล้ว นำเข้าภาพแล้ว มีวิดีโอแล้ว

## 6. นำเข้าและจัดไฟล์
- ZIP, story.json, ภาพ และวิดีโอ ตรวจไฟล์และ preview ก่อนนำเข้า
- จับคู่ไฟล์กับ EP/ฉาก เตือนซ้ำและก่อนเขียนทับ ห้ามจับคู่ผิดคน/ผิดฉากอย่างเงียบ ๆ
- รับภาพเพิ่มได้โดยไม่ต้องนำเข้าบทเดิมซ้ำ
- แจ้งฉากขาด ไฟล์ซ้ำ ตัวละครไม่ครบ บทพูดที่อาจยาวเกินเวลาฉาก
- ภาพ/วิดีโอเต็มจอ เก็บหลายเวอร์ชัน เลือกเวอร์ชันใช้จริง แก้เฉพาะชุด/สถานที่/กิจกรรมได้

## 7. วิดีโอ ปก และส่งออก
- Prompt Flow/Veo พร้อมคัดลอกต่อฉาก นำวิดีโอที่สร้างจริงกลับมาจับคู่ฉาก
- ไม่แสดงสถานะเรนเดอร์สำเร็จหากยังไม่มีไฟล์ ไม่สร้างเมนูเรนเดอร์หลอก
- ปกแนวตั้งและแนวนอน ส่งออกเฉพาะ EP หรือทั้งเรื่อง
- ส่งออก/สำรองงานระหว่างทำได้ แม้ยังไม่ครบ แยกจากสถานะหนังเสร็จแล้ว

## 8. ความมั่นคงและช่วยเหลือ
- บันทึกอัตโนมัติ สำรอง ZIP กู้คืน ยืนยันก่อนลบ ตรวจพื้นที่จัดเก็บ
- อัปเดตจาก director-x ตรวจ package/version/signature ติดตั้งทับเก็บงาน
- วิธีใช้และคัดลอกรายละเอียดข้อผิดพลาด
- ฟังก์ชันไม่พร้อมระบุชัดเจน ปุ่มใช้งานแล้วต้องมีผลจริงและผลลัพธ์ตรวจสอบได้

## 9. เกณฑ์ตรวจรับก่อนปล่อย
- ตรวจทุกเส้นทางเมนู ไฟล์ สถานะ ย้อนกลับ ส่งซ้ำ งานค้าง และการกู้คืน
- Compile และ unit tests ไม่ยืนยันการใช้งานจริงบนมือถือ
- ต้องทดสอบ share กับ ChatGPT บนอุปกรณ์ Android ที่ติดตั้งจริง: เปิดแยก ข้อความครบ ภาพครบ ส่งซ้ำและกลับมาทำต่อ
- รายงานให้ชัด: ผ่านทดสอบโค้ด / ผ่าน CI / ผ่านอุปกรณ์จริง / ยังไม่ได้ทดสอบ
- ห้ามรายงานใช้งานสมบูรณ์โดยไม่มีผลทดสอบรองรับ
- ทำภายในเป็นช่วง จัดการเรื่อง → บท/ตัวละคร → รับส่งไฟล์ → วิดีโอ/ส่งออก ตรวจทีละช่วงแล้วรวมอัปเดตเดียว
