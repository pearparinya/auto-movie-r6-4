# DIRECTOR X 1.59 — รวมหนัง EP เป็น MP4

## ใช้งาน
นำเข้า MP4 ทุกฉากและปกแนวตั้งของ EP แล้วเปิดเมนู 4 เลือก EP → ตรวจคลิปและรวม EP ตรวจรายการก่อนเลือกวิธีรวม ปกเปิดเสียงเงียบ 3 วินาที ผลลัพธ์ 1080×1920 เมื่อรวมสำเร็จใช้ดูหนัง ดาวน์โหลด MP4 หรือแชร์ ชื่อเริ่มต้น ชื่อเรื่อง_EP01_ชื่อตอน.mp4 ผ่านหน้าต่างเลือกตำแหน่งบันทึกของ Android
ปรับลำดับจากจัดลำดับคลิป คืนลำดับเลขฉากได้ คลิปต่างสัดส่วนเลือกเว้นขอบ/ครอปกลางพร้อมตัวอย่าง

## คุณภาพ
คุณภาพสูงใช้ H.264/AAC เข้ารหัสใหม่ ผู้ใช้ต้องยืนยันก่อนเริ่ม การแปลงอาจสูญเสียคุณภาพเล็กน้อย bitrate เป้าหมายอย่างน้อย 24 Mbps หรือจากต้นฉบับที่สูงกว่า สูงสุด 80 Mbps ค่าจริงขึ้นกับ encoder และภาพ ไม่อ้าง lossless ในโหมดนี้ ไม่เปิด fallback ลดขนาด หากอุปกรณ์ไม่รองรับให้แจ้งข้อผิดพลาด
ต่อโดยไม่เข้ารหัสใหม่ตรวจขนาด เฟรมเรต rotation codec/config และเสียง รวมปกเปิดก่อน ปกมักมี config ต่างจาก Flow จึงอาจต้องใช้โหมดคุณภาพสูง ขยาย 720p ไม่เพิ่มรายละเอียดจริง

## การเก็บงาน
เก็บต้นฉบับ ใช้สำเนาขณะรวม ผลลัพธ์แต่ละครั้งเป็นเวอร์ชันใหม่ มี foreground service ความคืบหน้า ยกเลิก และ wake lock เมื่อ Android ฆ่า process ต้องเริ่มใหม่ ไม่อ้างว่ากู้ต่อกลางงานได้ ตรวจขนาด/ความยาว/track เสียงก่อน complete รวมสำเร็จแยกจากดาวน์โหลดสำเร็จ หากคลิป ปก หรือลำดับเปลี่ยนหลังรวมให้แจ้งว่าเป็นเวอร์ชันเก่า ZIP ยังใช้เฉพาะชุดงานและสำรอง

## การตรวจรับ
มี unit tests ชื่อไฟล์ไทย/EP/ขนาดชื่อ/พื้นที่ และ Android instrumentation ที่สร้างคลิปจริง ทดสอบ foreground renderer ปกเหลือง 3 วินาทีต่อคลิปแดง/น้ำเงิน ตรวจ 1080×1920 ความยาว track เสียง สี/ลำดับฉาก และ hash ต้นฉบับไม่เปลี่ยน ดูผลของ commit ที่เผยแพร่ใน GitHub Actions การ compile ไม่ใช่การตรวจภาพและเสียงจริง
ยังไม่ได้ทดสอบคลิปจากบัญชี Flow ของผู้ใช้หรือเครื่องผู้ใช้จริง
