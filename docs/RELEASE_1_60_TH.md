# DIRECTOR X 1.60 (build 783)

- แก้การส่งคำสั่งไป ChatGPT ที่เปิดเป็นแชทเปล่าใน Android บางรุ่น
- ทุกเมนูใน Studio ใช้ตัวส่งกลางเดียวกัน และใส่คำสั่งไว้ทั้ง Share Text, ClipData และคลิปบอร์ด
- แนบสิทธิ์อ่านภาพทุกภาพใน payload เดียวกับข้อความ
- ไม่บันทึกว่าส่งสำเร็จจนกว่าผู้ใช้ยืนยันว่าเห็นคำสั่งและภาพใน ChatGPT
- เมื่อรับข้อมูลไม่ครบ สามารถส่งซ้ำหรือคัดลอกคำสั่งแล้วเปิดใหม่ได้

ข้อจำกัดของ Android: แอปต้นทางไม่สามารถกดวางหรือกดส่งแทนผู้ใช้ภายใน ChatGPT ได้ หาก ChatGPT รุ่นที่ติดตั้งละทิ้งข้อมูล Share Intent ผู้ใช้ต้องแตะช่องพิมพ์ค้างแล้วเลือก “วาง” จากคลิปบอร์ดที่ DIRECTOR X เตรียมไว้
