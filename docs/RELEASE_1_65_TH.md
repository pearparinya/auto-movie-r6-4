# DIRECTOR X 1.65 (build 788)

## รองรับ ZIP จาก ChatGPT ได้ทนทานขึ้น

- คัดลอก ZIP จากพื้นที่ดาวน์โหลดเข้าสู่พื้นที่ตรวจสอบของแอปก่อนแตกไฟล์
- อ่าน ZIP ผ่านสารบัญกลางแทนการอ่านสตรีมต่อเนื่อง เพื่อลดข้อผิดพลาด `Unexpected end of ZLIB input stream`
- หากรายการใดภายใน ZIP อ่านไม่ได้ แอปจะแสดงชื่อรายการนั้นและนำเข้าส่วนที่สมบูรณ์ต่อได้
- หลังนำเข้า ให้ใช้ `ตรวจงานที่ขาด` เพื่อเพิ่มเฉพาะภาพหรือปกที่ต้องแก้ ไม่ต้องเริ่มเรื่องใหม่
