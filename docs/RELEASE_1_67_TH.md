# DIRECTOR X 1.67 (build 790)

## กู้ชุดงาน ZIP ที่ไม่มี END header

- ตรวจจับ `zip END header not found` โดยตรง
- หาก ZIP ไม่มีสารบัญปิดท้าย ระบบจะอ่าน local entries ตามลำดับและกู้ `story.json` ภาพฉาก และปกที่สมบูรณ์
- แสดงคำเตือนว่าเปิดโหมดกู้ข้อมูล แต่ไม่หยุดการนำเข้าทั้งชุด
- หากรายการสุดท้ายไม่สมบูรณ์ ระบบจะข้ามรายการนั้นและให้ตรวจงานที่ขาดภายหลัง
